## Проверка кода и данных

- `node --check app.js`, `git diff --check` и
  `python3 build-catalog.py --validate-only` выполнены успешно.
- HTML/JS IDs и наличие локальных ресурсов проверены.
- CSS и JS используют одну границу `max-width: 991px`.
- Удалены file input, обработчики импорта/сброса и весь путь чтения IndexedDB.
  Приложение делает только запрос общего `catalog.json`; localStorage используется
  для избранного. Старое хранилище не удаляется и не читается.
- Независимый review проверил init на нормальной/пустой базе, ошибке сети,
  HTTP-ошибке, некорректном JSON и неподдерживаемой схеме: один fetch и ноль
  обращений к IndexedDB во всех шести сценариях.

  корректная полная база, отсутствие optional totals, несовпавшие counts,
  non-runtime recipe, отсутствующая иконка, дата без timezone, старая и будущая дата.
