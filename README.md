# LoliLand · TMR

Минималистичный веб-просмотрщик рецептов TechnoMagic RPG для GitHub Pages.
Статические HTML/CSS/JS; установка и сервер приложению не нужны.

## Интерфейс

- Поиск по названию, английскому имени, ID и `@моду`.
- Рецепты, применение ингредиентов, альтернативы и количества.
- Верстаки до 9×9, бесформенные крафты и механизмы.
- Избранное, переходы между ингредиентами, прямые ссылки на предмет.
- Клавиши `/`, `R`, `U`, `Esc`; мобильный интерфейс.
- Тёмные полупрозрачные панели в чёрно-белой палитре.

## Запуск

```sh
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`. Для GitHub Pages используется
`.github/workflows/pages.yml`: push в `main` проверяет данные и публикует файлы приложения.

## Подключение текущей базы

Положить нормализованную выгрузку в `current/catalog.json`, а её
изображения — в каталог проекта. Затем:

```sh
python3 build-catalog.py --require-complete
```

Скрипт не обращается к архивным источникам. Рецепты принимаются только с
`verification: "runtime"`, а дата `meta.exportedAt` должна быть не старше 14
дней. Дата `checkedAt` означает лишь проверку источников и не подтверждает
свежесть рецептов. Если базы нет, сборка оставляет честный пустой экран.

Полная база требует подтверждения серверной синхронизации, SHA-256 манифеста
клиента и инвентаря обработчиков рецептов с совпавшими исходными и выгруженными
счётчиками. Новая дата у старого файла не делает его актуальным.

JSON можно загрузить и локально через настройки сайта. Импорт остаётся в
браузере пользователя и не изменяет общую опубликованную базу.

## Формат

Верхний уровень: `schemaVersion: 1`, `meta`, `mods`, `items`, `recipes`.
Предмет: уникальные `id`, `name`, `modId`, `icon`; ID различает значимые
metadata/NBT-варианты. Рецепт: уникальный `id`, `type`, массивы `inputs` и
`outputs`. Стек: `itemId`, положительное `count`, необязательные `unit`,
`alternatives`, `chance` (строго от 0 до 1).

Для shaped-рецепта нужны `width`, `height` и `slot` каждого входа. Нумерация
слотов начинается с нуля. Для машин и бесформенных рецептов расположение не
выдумывается. Условия сохраняются в `conditions`, название механизма — в
`machine`.
