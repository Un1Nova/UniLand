# UniLand · TMR

Статический каталог LoliLand TechnoMagic RPG: крафты, карта квестов и библиотека
гайдов. [Открыть сайт](https://un1nova.github.io/loliland-atlas/).
HTML/CSS/JavaScript, без сервера приложений; публикация через GitHub Pages.

## Текущий снимок

Minecraft 1.7.10, runtime-выгрузка **3 ноября 2026, 15:47:47 МСК** после
подключения к серверу и синхронизации рецептурных скриптов.

- 25 056 вариантов предметов с metadata/NBT и 174 жидкости/газа.
- 30 291 рецептурная запись (разные представления одного механизма не
  считаются уникальными механиками).
- 989 квестов, 9 глав с исходными координатами и зависимостями.
- 26 активных гайдов и 796 страниц вики из ресурсов клиента.
- 306 больших shaped-рецептов с исходной сеткой 9×9.

Статус **partial** сохранён намеренно. У 515 записей специальные правила ещё
не полностью преобразованы в удобную схему входов/выходов; их идентификаторы,
источники и метаданные сохранены в `data/normalization-report.json` и
`data/recipe-details/`. Полные типизированные исходники находятся в локальном
архиве выгрузки. Эти записи нельзя считать полноценным симулятором механик.
Клиентские реестры не доказывают полноту данных, хранящихся только на сервере.
29 технических предметов имеют прозрачные иконки, для 8 wildcard-вариантов
указаны репрезентативные иконки; у одной жидкости нет исходной runtime-иконки.

`data/snapshot.json`, `data/coverage-report.json` и `data/client-manifest.json`
содержат происхождение снимка, ограничения и контрольные суммы. Отсутствие
записи не означает отсутствия рецепта на сервере.

## Интерфейс

- Поиск по русскому/английскому названию, ID и `@моду`, избранное.
- Пагинация предметов и библиотеки с размером страницы под окно.
- Крафты и применения, переходы по ингредиентам, количества и альтернативы.
- Сетки до 9×9 с сохранением пустых ячеек.
- Карта квестов: масштаб, перемещение, зависимости, задания и награды.
- Отметки выполнения квестов сохраняются на устройстве, не синхронизируются с игрой.
- Гайды с переходами к предметам; клавиши `/`, `R`, `U`, `Esc`.
- Монохромные стеклянные панели в духе Apple, цветные спрайты с яркостью 150%.
- Выдача ограничена окном; длинные описания прокручиваются внутри панели без
  видимой полосы прокрутки. Поиск закреплён снизу.

## Локальный запуск

```sh
python3 -m http.server 8080
```

Открыть `http://localhost:8080`.

## Проверка и публикация

```sh
python3 build-catalog.py
python3 validate_release.py
node --check app.js
node --check knowledge.js
python3 -m unittest test_prepare_site.py test_catalog_contract.py
python3 exporter/test_web_grids.py
python3 prepare_site.py
```

`prepare_site.py` создаёт новый `_site` из разрешённого списка UI-файлов,
JSON и изображений, проверяет ссылки. Каталог назначения должен быть пустым.
Игровые JAR, сырые дампы, логи, исходники экспортёра и личные файлы в `_site`
не входят.

Push в `main` запускает `.github/workflows/pages.yml`. Текущий partial-снимок
публикуется как одобренная владельцем версия от 3 ноября 2026.
`release.json` фиксирует канонический SHA-256 каталога, статус и счётчики.
`validate_release.py` проверяет этот снимок, свежесть (до 14 дней), серверную
синхронизацию, манифест клиента, полноту ссылок на метаданные и квесты,
совпадение отчёта о ненормализованных правилах.

Проверка `build-catalog.py --require-complete` сохранена для действительно
полной базы; текущий partial-снимок её **не проходит**. Для `status: complete`
проверка выпуска обязательно применяет полные требования. Даты и флаги
полноты нельзя менять ради прохождения CI.

## Обновление данных

Код извлечения находится в `exporter/`. Последовательность:

1. Получить новый снимок живых реестров после серверной синхронизации,
   квестовые определения и активные ресурсы; сохранить сырой снимок вне репозитория.
2. Сформировать пакет через `build_map_data.py`, `enrich_map_links.py`,
   `finalize_map_package.py`; проверить `audit_map_data.py` и
   `verify_map_package.py`. Параметры доступны через `--help`.
3. Выполнить `python exporter/prepare_web_data.py <пакет> <репозиторий>`.
   Скрипт переносит публичные данные и нормализует координаты больших крафтов.
4. Проверить пробелы покрытия, интерфейс и новый снимок. Обновить `release.json`
   его фактическими счётчиками и хешем `validate_release.fingerprint(catalog)`.
5. Выполнить проверки выше и отправить в `main`.

Нужен реальный новый runtime-снимок: перепаковка старого JSON не обновляет
`exportedAt`. Схема: `schemaVersion: 1`, `meta`, `mods`, `items`, `recipes`.
У shaped-рецептов размеры `width`/`height` и уникальные `slot` от нуля.
Жидкости имеют собственный ID и единицу `mB`; варианты с разными количествами
сохраняются в `variants`. Запись без фиксированного выхода допускается только
с `operation: native-rule`, источником и отдельными метаданными.

Неофициальный проект. Игровые названия и изображения принадлежат их авторам.
[Официальный сервер](https://loliland.ru/ru/servers/techno-magic-rpg).
